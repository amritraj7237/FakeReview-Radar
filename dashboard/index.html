FakeReview Radar

Review quality & rating-skew analyzer · PST_DA_006 · Chirag Malik & Amrit Rai
Heuristic indicator, not proof. The trust score (1–100) summarises warning signals in the ratings, verification and review dates. A low score means “worth a closer look”, never “this seller is fraudulent”. It is not a probability that the reviews are genuine.

Synthetic products have known labels, so we can measure the flag (trust < 66). The signal settings were chosen on the tuning set (seed 42) and real data only. The test set (seed 7) was not used while tuning. The stress set uses smaller, slower, better-hidden attacks the rules never saw. These numbers are about simulated patterns, not accuracy on real-world fake reviews.

From reviews to a trust score
  1. Clean the reviews (rules R0–R8, every change logged; see Data quality).
  2. Count stars per product, shrink the shares toward a typical product (k = 10 imaginary reviews) so tiny products aren’t flagged by luck.
  3. Measure four warning signals, each a strength s from 0 to 1, or “not measured”.
  4. Combine them with noisy-OR: R = 1 − Π(1 − c·s), then Trust = round(1 + 99 × (1 − R)).

One strong signal can pull the score down on its own; several weak ones add up; a signal that is silent or missing never raises the score. BSI alone can only lower trust to 51, because polarised ratings have innocent causes (a genuinely divisive product).
Bands
Products with fewer than 5 valid ratings get no score (“insufficient data”); 5–19 ratings get a low-sample warning.
Limitations
  • No real fake/real labels exist. Accuracy is measured on simulated data only.
  • Real data: first 1,000,000 lines of Amazon Reviews 2023 Electronics, i.e. all reviews by a set of reviewers, so each product shows a subset of its reviews and bursts are thinned out.
  • Small, slow attacks (stress set) mostly get through.
  • Text, reviewer history and seller data are not used.
